# Татьяна Верг — сайт-витрина

Одностраничный адаптивный сайт на HTML, CSS, Tailwind CDN и нативном JavaScript. Сборка не требуется.

## Запуск локально

Откройте `index.html` в браузере или запустите любой статический сервер в корне проекта.

## Публикация через GitHub Pages

1. Откройте **Settings → Pages** в репозитории.
2. В разделе **Build and deployment** выберите источник **GitHub Actions**.
3. Файл `.github/workflows/deploy.yml` автоматически соберёт и опубликует сайт после нового коммита в ветку `main`.
4. Откройте вкладку **Actions**, чтобы проверить публикацию. Готовый адрес появится в **Settings → Pages** после успешного запуска.

## Перед рекламным запуском

- Замените демонстрационные фотографии в галерее на реальные работы Татьяны и учеников с разрешением на публикацию.
- Проверьте точную формулировку чемпионского статуса и номинации Siberian Nail Fest 2025.
- Подтвердите дату ближайшего потока, состав программ, цены и форматы обучения.
- Для прямой ссылки WhatsApp укажите подтверждённый номер в формате международного кода. Сейчас кнопка открывает WhatsApp с подготовленным текстом, но не адресует сообщение конкретному номеру.
- Не публикуйте обещания фиксированного дохода учеников без подтверждённых кейсов и пояснения условий.
